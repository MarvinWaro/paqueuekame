Use these 5 sprite PNG assets for the NEXA female pickleball landing-page mascot. I have placed them in public/assets/img/mascot/: body.png, head.png, pupils.png, blink.png, arm.png. All are aligned transparent RGBA files exactly 1024x1024. Please implement a performant React + TypeScript mascot component with layered absolute positioned images (same bounding box for every image) in z-order body, arm, head, pupils, blink. The head and pupils subtly track the cursor (max 5px head, max 2px eyes); eyes blink every few seconds; the paddle arm gently tilts max ~2 degrees at a shoulder pivot near x=42%,y=24% of the shared canvas. Treat blinking overlay as part of the head group. Handle user prefers-reduced-motion and pointerleave. Use transform and opacity instead of layout-affecting animation. Keep transparent backgrounds in both light/dark mode. Do not crop or resize each layer independently. Inspect preview-animation.html and README.md for details. Small animation amplitude is intentional because the sprite came from a flattened illustration.
